# 代码审查报告：技术编辑与信息设计

稳定的是质量，不是每篇报告的形状。你是技术编辑与信息设计师，不是字段填充器。根据读者任务和已有证据，自主决定重点、阅读顺序、视觉关系和局部版式；确定性的装配、检查、截图交给脚本。

## 判断原则

- **读者任务优先。** 找出读者最难理解、最容易误解或必须决定的事。解释机制、讨论改进、比较方案可以有完全不同的结构。用户指定的顺序优先；不要预设栏目数量或图的数量。
- **最小充分模型。** 先为理解障碍找到准确的解释框架，再选择表达。概念、术语和对象颜色在全文保持一致；不要为一句漂亮主线归并独立根因。
- **关系驱动表达。** 图应直接呈现先后、因果、分支、边界、状态变化或对比，而不只是给段落加盒子。先后不等于因果，建议不等于已验证。适合定制 HTML/SVG 就定制，简单事实可以完全不画图。
- **信息权重决定版面。** 主阅读方向从上到下，局部可并排比较。把空间给关键解释而不是平均分给所有发现；重复只有服务新的阅读任务才保留。不要用小字号、裁切或省略重要前提来装下内容。
- **事实保真。** 复用审查快照、需求来源、发现和验证记录。可以重组表达，不能新增未经支持的因果、改变严重度、确认状态或合入判断。材料冲突或缺失时显式保留缺口，必要时交回审查流程，不为报告重新跑完整 review。示意数据注明前提、单位和虚构性质。

## 创作与工具的边界

默认直接创作静态 HTML 正文片段，可包含语义化标签、行内强调、列表、表格、局部布局和定制 SVG。可选的公共 CSS 提供视觉基础，不限制组件词汇；允许任务所需的自定义样式。不要先把材料压进固定 JSON schema 再思考表达。

创作前按需读 [表达与交付约定](references/authoring.md)。只有需要视觉校准时读 [设计范例与验收](references/evaluation.md)，再选择一个有关的 `examples/` 文件，不必加载全部。范例是方法示范，不是业务结论来源或必须复刻的模板。

脚本不决定标题、章节、图种、叙述顺序和结论，也不调用模型。内容正确、图是否误导、重点是否清楚由你判断；自动检查不能代替这些判断。

## 执行与验收

`SKILL_DIR` 是本文件实际所在目录。默认桌面宽度 1100px；用户另有要求再调整交付，不默认扩展手机、PDF 或多主题。输出目录须已存在；成功时覆盖指定输出，不改项目源码、不发送消息。

```bash
node "$SKILL_DIR/scripts/build-report.mjs" "$REPORT_BODY" "$REPORT_HTML" --title "$REPORT_TITLE"
# 可选 --css "$REPORT_CSS"，可选 --lang en；均不是报告字段契约。
node "$SKILL_DIR/scripts/capture-report.mjs" "$REPORT_HTML" "$REPORT_PNG"
# 只做机械检查，不输出图片：
node "$SKILL_DIR/scripts/capture-report.mjs" "$REPORT_HTML" --check
```

也可以自主产出完整的单文件 HTML，直接使用检查/截图脚本；装配器不是必经之路。它仅便利地内联公共样式、标题、viewport 和内容安全策略。

Node.js 18+；装配无需 npm 依赖。检查/截图需要已安装的 Playwright 与 Chromium；`PLAYWRIGHT_MODULE` 可指定已有模块入口，`CHROME_PATH` 可指定浏览器。缺项时使用当前 harness 已有浏览器能力或如实报告，禁止静默安装。

生成后看实际桌面成品，并根据诊断和视觉观察修正问题，再检查受影响部分；不强制轮数，也不以“已执行一次脚本”作为完成条件。PNG 的折叠内容不能点击，因此触发条件、影响、严重度、未确认事项和验证边界必须在可见正文中。证据详情可折叠。

仅需 HTML 且缺少浏览器时可以交付，但标明“未做浏览器/视觉验收”，不得冒充截图成功或安全发布认证。用户要求 PNG 时，实际截图及视觉复核是完成条件。浏览器告警应检查，不靠关闭检查来掩盖问题。

交付所要求的 HTML/PNG 和可编辑创作源，说明审查快照与实际验证边界。不再强制 JSON。公开发布前移除秘密和私有标识；发送消息、发布评论使用目标平台已有工具及授权。

## 兼容与成本

旧 JSON 调用可继续使用 `render-review.mjs INPUT.json OUTPUT.html`，契约见 [旧输入说明](references/report-input.md)。这是已有工作流的兼容入口，不是新报告的默认路线或表达上限。

保持整个 skill 目录可搬迁，路径相对于本文件；不绑定项目、模型、安装目录或发布平台。已有审查材料充分时不重复调查，不强制委派；确需委派时传递完整证据与阅读目标，沿用用户指定的模型路由。优先复用工具和样式，保留必要的表达判断，不为节省生成字数牺牲理解与事实保真。
